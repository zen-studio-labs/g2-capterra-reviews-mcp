# Changelog

## 0.1.0

First release.

- Remote MCP server with five software review tools: G2, Capterra, TrustRadius and Gartner Peer Insights, plus one tool that collects a product's reviews from several sites at once by product name. Ratings, pros and cons, full text, reviewer job title, industry and company size, sub-ratings, alternatives and switching reasons.
- Apify sign-in (OAuth) for Claude, ChatGPT, Cursor, VS Code, Codex and other remote MCP clients; token header as an alternative.
- Claude Code plugin with the software reviews skill: run flow for longer requests, which tool fits which question, input recipes per site, field sets and personal-data handling.
- Client configuration examples, code examples for Python, JavaScript and HTTP, and an MCP Registry manifest.
